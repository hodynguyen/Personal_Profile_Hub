## Notes
API endpoints:
- GET /api/portfolio (returns projects, experiences, skills)
- POST /api/contact (submits contact form)
Font setup:
- Primary: 'Inter' or 'Plus Jakarta Sans' for a clean tech look
- Display: 'Outfit' or 'Space Grotesk' for headings to give a modern developer feel
Dark mode is the default preference for "tech/dev" portfolios.
